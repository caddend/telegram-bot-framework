# Локальный Telegram Echo-Bot с веб-интерфейсом

Проект представляет собой полностью автономный эмулятор базового Telegram Bot API (`getUpdates`, `sendMessage`), встроенный эхо-бот и веб-мессенджер для тестирования без необходимости подключения к интернету или регистрации настоящего бота в Telegram.

## Требования

- Python 3.8 или новее.
- Сторонние библиотеки не требуются (используются только стандартные модули `http.server`, `urllib`, `threading`, `json`).

## Запуск одной командой

Перейдите в директорию с проектом и выполните:

```bash
python server.py
```

После старта в консоли появится сообщение:
```text
Сервер запущен на http://127.0.0.1:8080
```

## Использование

1. Откройте любой современный веб-браузер и перейдите по адресу:
   ```text
   http://127.0.0.1:8080
   ```
2. В нижней строке ввода наберите сообщение и нажмите кнопку **«Отправить»** (или клавишу `Enter`).
3. Сообщение появится в окне переписки, после чего фоновый эхо-бот автоматически получит обновление через эмулируемый метод `getUpdates` и вернет ответ в формате `Эхо: <ваш текст>` через метод `sendMessage`.

## Остановка сервера

Для завершения работы сервера нажмите `Ctrl + C` в окне терминала.
